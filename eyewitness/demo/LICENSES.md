# Demo licences

Generated media lives outside the repo in the demo folder. This file
lists the licence for each source the demo build uses.

| Source | Licence and note |
|---|---|
| Comic panels from Muse Image (`muse-image-1.0`) | Generated for this demo through the Meta Model API. No third party artwork. |
| Blink clips, crash screen and voice notes in the synthetic and golden folders | Made on this machine for the demo. No customer photos. |
| ffmpeg `flite` placeholder voice | The flite voice in ffmpeg is used only for the draft cut. The file name marks it as a placeholder. Andrei replaces it with a recording before the final cut. |
| Music | None. The demo carries voice and picture only. |

No passwords, tenant names, host names or network addresses appear in
any demo script. Recording scripts take every address and ticket
number from arguments or environment variables.
